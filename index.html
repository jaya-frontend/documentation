Introduction Variables Data Types Functions Loops
Introduction

JavaScript is a programming language used to make websites interactive.

It works with HTML and CSS to create dynamic web pages.

console.log("Hello World");
Variables

Variables are used to store data.

JavaScript has three ways to declare variables.

let name = "Jaya"; const age = 23;
  • var
  • let
  • const
Data Types

Data types define the type of value stored in a variable.

JavaScript has different data types.

let number = 10; let text = "Hello";
  • String
  • Number
  • Boolean
  • Undefined
Functions

Functions are reusable blocks of code.

They perform specific tasks.

function greet() { alert("Hello"); }
Loops

Loops are used to repeat a block of code.

JavaScript supports different types of loops.

for(let i = 0; i < 5; i++) { console.log(i); }
  • For Loop
  • While Loop
  • Do While Loop
